This project is a Sign Detection System built using OpenCV and Machine Learning.
It can detect and classify  signs from images using extracted features and a trained model.

The system follows a complete pipeline:

Image preprocessing
Feature extraction
Model training
Real-time / image-based prediction

🎯 Features
Detects alphabetical signs from input images
Uses OpenCV for image processing
Extracts meaningful features for classification
Trained ML model for prediction
Simple and easy-to-use scripts

🛠️ Tech Stack
Python 🐍
OpenCV
NumPy
Scikit-learn (for model training)
